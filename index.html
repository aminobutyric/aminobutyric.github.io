The problem

Most agents get the keys to the host.

File access, shell, and network make agents useful — and make prompt injection, secret theft, and a wrecked working tree ordinary risks. Approving every call is fatigue. Skipping approvals is hope. Warrant moves the boundary to actions the controller can enforce.

How it works

Four steps. One trusted loop.

  1. 01

    Point at a project

    Warrant copies a disposable snapshot. Symlinks, secrets, and excluded paths never enter the workspace the model can see.

  2. 02

    The model proposes actions

    Only a closed, versioned schema: list, read, search, patch, diff, named recipes. Unknown fields are rejected.

  3. 03

    Policy decides

    Allow, ask, or deny — deterministically. Ask requires a grant. Deny wins. The model never sets the rules.

  4. 04

    You keep the original

    A unified diff is the only artifact written outside application state. Applying it is a human action.

Policy

Allow, ask, or deny — without asking the model.

Select an action. The decision is deterministic. Deny wins over ask. Ask wins over allow.

Security invariants

Defaults you cannot prompt away.

  • / 01

    No ambient access

    The model cannot touch files, processes, credentials, or networks. It proposes typed actions. A trusted controller decides.

  • / 02

    Disposable workspace

    Each task creates a disposable copy. Patches publish as generations. You export a reviewable diff. The original tree stays yours.

  • / 03

    Exact grants

    Ask decisions require an exact action or a bounded recipe grant — uses, expiry, and a configuration digest. Vague session trust is not a thing.

  • / 04

    Offline verification

    Tests run in a rootless, network-none sandbox with pinned image digest, dropped capabilities, and hard resource limits.

  • / 05

    Untrusted input

    Model output, repository files, tool results, and dependency output are all untrusted. Policy does not consult an LLM.

  • / 06

    Audit by default

    Every proposed and executed action leaves a redacted JSONL record. Secrets are stripped before persistence.

Who it is for

Built for people who already feel uneasy.

  • Daily driver, not YOLO

    You want an agent on real work without handing it a shell on the host. Control should feel like power, not paperwork.

  • Local and sovereign

    Ollama stays first-class. Remote models can be adapters later. The governance layer does not change with the brain.

  • Security-minded

    You will read the threat model. Adversarial files, path races, and grant replay are tests — not blog claims.
